### 2026-06-04
**OpenRouter Migration for Trading Bot**
- **AI provider layer** — `node-projects/my-app/src/lib/ai.ts`:
  - Replaced the prior OpenRouter model chain (returning empty responses in production) with: `OPENROUTER_MODEL` env override → `google/gemma-4-31b-it:free` → `openai/gpt-oss-20b:free` → `nvidia/nemotron-3-nano-30b-a3b:free`.
  - All three providers (OpenAI, OpenRouter, Ollama) continue to be exposed via `chatAI()`; `chatAI()` provider-selection and fallback semantics are unchanged.
- **`parseJSON` hardening** — same file. Added prefix-strip and array-match fallback stages; the old single `{[\s\S]*}` regex was over-matching into prose.
- **Report history route** — `node-projects/my-app/src/app/api/trading-bot/report-history/route.ts`:
  - 50-trade, 500-trade, and global-recommendation generators now all force `provider: 'openrouter'`.
  - `mergeNoteUpdates` filters malformed legacy items whose `content` looks like raw JSON, and defaults unknown action verbs to `add`.
  - Prompts strengthened to demand "Output ONLY the JSON array. No prose, no labels, no code fences." plus a per-content length constraint (15–30 words).
  - `maxDuration` raised to 300s to tolerate OpenRouter free-tier latency.
- **Learning Board UI** — `node-projects/my-app/src/app/trading-bot/components/ReportCard.tsx`, `AIReportsSection.tsx`, `TradeHistorySection.tsx`, `page.tsx`: refactored report card into a unified "Learning Board" view.
- **Tooling** — `tools/test-strategy-edge.js` and `tools/trade-filter-analysis.js` updated alongside.
- **Versioning** — `node-projects/my-app/src/data/versions.json`: my-app bumped 1.2.0 → 1.2.1.

### Impact
- Trade-analysis notes generation no longer silently fails in production — at least one model in the new chain is reliably returning a payload.
- `parseJSON` no longer throws away valid array payloads (a known failure mode of the prior single-regex strategy).
- `mergeNoteUpdates` can no longer be silently dropped by an unknown action verb, and no longer carries forward malformed legacy items into the active set.
- Report card is now visibly labelled "Learning Board" across the trading-bot dashboard.
