# PS3 Controller Visualizer

Realtime DualShock particle visualizer for streaming. Displays controller input with visual effects.

## Features

- DualShock 3/4 controller support via Gamepad API
- Particle burst effects on face button presses
- Flame exhaust effect on L2/R2 triggers (with heating animation)
- D-pad with cyan glow effects
- Analog stick visualization
- Draggable elements for custom positioning
- Debug mode for development
- Compact visualizer for OBS overlay

## Tech Stack

- React 19 / Next.js 15
- HTML5 Gamepad API
- Tailwind CSS
- TypeScript
